# My Portfolio

A responsive personal portfolio built with React and Vite.

## Run locally

1. Install Node.js (LTS).
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open the local URL printed by Vite.

Create a production build with `npm run build`.

## Personalize your portfolio

Open `src/App.jsx` and replace the starter values in the `profile`, `skills`, and `projects` constants with your own information. Update the social links, project URLs, and initials/logo. The current content is placeholder copy because no personal bio, skills, links, or project details were included in the repository request.

To add a profile photo, replace the illustrated visual in the `.hero-art` section with an `<img>` and add your image under `public/`.
